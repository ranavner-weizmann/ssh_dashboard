OneDrive Backup

Copies the sessions already downloaded to this computer into a folder in your OneDrive, and lets you explore them from there.
Only data already on this computer is backed up. This copies the sessions in … - what you downloaded from the Pi with "Download Data" on the connected dashboard. It does not read anything from the Pi itself. Download first, then back up.
Nothing is deleted, and the cloud copy follows OneDrive's sync. Files are copied, never moved. Right after a backup the copy exists in the OneDrive folder on this disk; it is in the cloud only once the OneDrive app has finished uploading it (check its icon in the taskbar). Sessions already backed up are brought up to date: files that are new or changed are copied again, unchanged ones are skipped.
